# Ejercicios de Java
Repositorio de proyectos y ejercicios académicos desarrollados en Java como parte de mi formación en Ingeniería en Sistemas de Información.

Descripción

Este repositorio contiene código fuente, archivos de datos y recursos relacionados con actividades de programación en Java.

Incluye archivos CSV utilizados como datos de entrada para ejercicios relacionados con distintos contextos, como información de hoteles, facturación y productos textiles.

Tecnologías y herramientas
Java: desarrollo de los programas.
CSV: almacenamiento e intercambio de datos tabulares.
NetBeans: configuración de proyecto mediante archivos de nbproject y build.xml.
IntelliJ IDEA: archivos de configuración del proyecto presentes en el repositorio.

Cómo obtener el proyecto

Clona el repositorio con Git:

git clone https://github.com/diwgod55/ejercicios-java.git
cd ejercicios-java
Ejecución
Abre el proyecto en NetBeans o IntelliJ IDEA.
Revisa los archivos de código fuente dentro de src.
Identifica la clase que contiene el método main.
Configura el proyecto con un JDK compatible.
Ejecuta la clase correspondiente a la actividad que quieras probar.

Si una actividad utiliza archivos CSV, asegúrate de que estén disponibles en la ruta que espera el programa.

Objetivos académicos
Fortalecer las habilidades de programación en Java.
Practicar el procesamiento de información.
Trabajar con archivos CSV.
Organizar proyectos y recursos de desarrollo.
Aplicar conceptos de programación en ejercicios prácticos.
